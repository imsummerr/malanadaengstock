# 🔔 เตือนเช็คสต็อก

ส่งข้อความเตือนเข้ากลุ่มไลน์ของแต่ละที่ **ทุกวันอาทิตย์** และ **ทุกวันสุดท้ายของเดือน** ตอน 1 ทุ่ม

```
📋 ถึงเวลาเช็คสต็อก — ครัวกลาง

วันอาทิตย์แล้ว อย่าลืมนับสต็อกให้ครบทุกรายการ

เข้าเว็บสต็อก → "เช็คสต็อกรายสัปดาห์"
เลือกสถานที่ ครัวกลาง แล้วนับให้ครบ

นับเสร็จแล้วยอดในระบบจะกลับมาตรงกับของจริง
แล้วดูของหายได้ที่หน้าสรุปยอดขาย แท็บ "คำนวณของหาย"
```

**นับไปแล้ววันนั้น จะไม่เตือนซ้ำ** — ระบบเช็คให้ก่อนส่ง

---

## ⚠️ ไฟล์นี้ไม่ได้คำนวณของหาย

**ของหายมีอยู่แล้ว** ในหน้า **สรุปยอดขาย → แท็บ 🔎 คำนวณของหาย**

ของเดิมทำได้ละเอียดกว่า:

- คำนวณทีละรายการ พร้อมมูลค่าเป็นเงิน
- **หักเดลิเวอรี่ ส่วนลด และน้ำจิ้มแถม** ออกก่อนเทียบ
- สรุปให้เลยว่า `✅ ยอดขายครอบคลุมมูลค่าของที่ใช้ไป` หรือ `⚠️ ยอดขายน้อยกว่าที่ควรได้ X บาท`
- ซ่อนรายการที่ไม่หายได้ · เห็นเฉพาะเจ้าของร้าน

> 💡 **ทำไมไม่เขียนซ้ำในไลน์** — ถ้าคำนวณสองที่แล้วเลขไม่ตรงกัน จะไม่รู้ว่าควรเชื่ออันไหน
> มีที่เดียวแล้วเชื่อได้ ดีกว่ามีสองที่แล้วสงสัยทั้งคู่

พิมพ์ `ของหาย` ในไลน์ บอทจะบอกทางไปหน้านั้นให้

---

## ทำไมต้องนับให้ตรงเวลา

ยอดขาย**ไม่ได้ถูกหักออกจากสต็อกทีละบิล** การนับจริงจึงเป็นอย่างเดียวที่ทำให้ยอดกลับมาตรง
และเป็นจุดตั้งต้นให้คำนวณของหายรอบถัดไป

นับไม่สม่ำเสมอ = ช่วงเทียบกว้างจนหาสาเหตุไม่เจอว่าของหายตอนไหน

---

## ติดตั้ง

### 1) เอาโค้ดเข้า Apps Script

กด **+** → **สคริปต์** → ตั้งชื่อ `stock-audit` → วางโค้ดจาก [`stock-audit.gs`](./stock-audit.gs)

ต้องอยู่โปรเจกต์เดียวกับ `pos-backend.gs` เหมือนไฟล์อื่น

### 2) ตั้งตัวเตือน

รัน **`setupStockAuditTriggers`** ครั้งเดียว

### 3) ฟังก์ชันที่ใช้ได้

| ฟังก์ชัน | ทำอะไร |
|---|---|
| `setupStockAuditTriggers` | ตั้งตัวเตือน (รันครั้งเดียว) |
| `testRemindNow` | ลองส่งข้อความเตือนเดี๋ยวนี้ ไม่ต้องรอวันอาทิตย์ |
| `whoCountedToday` | เช็คว่าที่ไหนนับไปแล้วบ้างวันนี้ |

---

## หมายเหตุ

- เตือนไปที่กลุ่มเดียวกับที่ตั้งไว้ใน `LINE_GROUPS` — ที่ไหนไม่ได้ตั้งกลุ่มก็ไม่ได้รับ
- trigger รัน**ทุกวัน** แต่ตัวมันเองเช็คว่าวันนี้ต้องเตือนไหม
  ทำแบบนี้เพราะเดือนมี 28–31 วัน ตั้ง trigger วันสิ้นเดือนตรง ๆ ไม่ได้
- ไม่แตะชีตอะไรเลย อ่านชีตเช็คสต็อกอย่างเดียวเพื่อดูว่านับไปแล้วหรือยัง
