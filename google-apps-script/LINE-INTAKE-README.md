# 📥 ส่งไลน์ → บันทึกลงชีตให้เลย

ซื้อของมาแล้วพิมพ์ในไลน์บรรทัดเดียว หรือถ่ายรูปบิลส่งไป บอทอ่านแล้วลงชีตให้ทันที
ไม่ต้องเปิดเว็บ ไม่ต้องล็อกอิน

```
คุณ:  สลีปดอลลี่ 68 บาท 800 กรัม

บอท: ✅ บันทึกแล้ว 1 รายการ

     • ปลาดอลลี่ — 68 บาท / 800 กรัม (85 บาท/กก.)

     รวม 68 บาท · วันนี้ทั้งหมด 1,240 บาท

     ผิดตรงไหนพิมพ์ "ลบ" ได้เลย
```

พิมพ์ผิดชื่อได้ — "สลีปดอลลี่" กับ "สไลด์ดอลลี่" บอทรู้ว่าหมายถึง **ปลาดอลลี่** ในชีตรายการสินค้า

| ส่งอะไรได้ | ต้องมีอะไร | ค่าใช้จ่าย |
|---|---|---|
| 💬 **ข้อความ** | ไม่ต้องมีอะไรเพิ่ม | **ฟรี** ไม่จำกัดจำนวน |
| 📷 **รูป** — แบบฟรี | เปิดบริการ Drive API ในโปรเจกต์ | **ฟรี** ใช้ OCR ของ Google (ค่าเริ่มต้น) |
| 📷 **รูป** — แบบแม่นกว่า | ตั้ง `ANTHROPIC_API_KEY` | ราว ๆ **1 บาท/รูป** ให้ Claude อ่านให้ |

> **เลือกยังไงดี** — บิลพิมพ์จากเครื่อง ตัวหนังสือคมชัด **OCR ฟรีเอาอยู่**
> แต่ถ้าเป็นลายมือเขียน บิลยับ ๆ ถ่ายเอียง หรือตัวเลขติดกันแน่น OCR จะเริ่มเพี้ยน
> ตรงนั้น Claude อ่านดีกว่ามาก — เริ่มจากฟรีก่อน ไม่พอค่อยเปิดอีกทางได้ตลอด

## พิมพ์ได้แบบไหนบ้าง

สลับลำดับได้ ไม่ต้องเว้นวรรคก็ได้ ใส่ครบทุกช่องหรือไม่ครบก็ได้:

```
ปลาดอลลี่ 68 บาท 800 กรัม
ปลาดอลลี่ 800 กรัม 68 บาท
ดอลลี่68บาท800กรัม
หมูสันคอ 2 กก. 350
ผักกาดขาว 3 ถุง 60 บาท
ปูอัด 250                    ← เลขเปล่า ๆ ถือเป็นราคา
มาม่า 2 ลัง 1,200 บาท
```

หลายรายการรวดเดียว — บรรทัดละอย่าง หรือคั่นด้วยจุลภาค:

```
ปลาดอลลี่ 68 บาท 800 กรัม
ปูอัด 120 บาท
ผักกาดขาว 3 ถุง 60
```

**หน่วยที่รู้จัก**

| ประเภท | คำที่พิมพ์ได้ |
|---|---|
| น้ำหนัก | กรัม, ก., g, กก., กิโล, กิโลกรัม, โล, kg, **ขีด** (1 ขีด = 100 กรัม) |
| เงิน | บาท, บ., ฿, baht |
| จำนวน | ถุง, แพ็ค, ชิ้น, อัน, ไม้, กล่อง, ลัง, มัด, กระปุก, ฝัก, ห่อ, แผ่น, ตัว, ใบ, ฟอง, ขวด, กระป๋อง, ที่ |

**คำสั่งอื่น**

| พิมพ์ | ได้อะไร |
|---|---|
| `ลบ` หรือ `ยกเลิก` | ลบรายการล่าสุดที่ตัวเองเพิ่งบันทึก |
| `ยอดวันนี้` หรือ `สรุป` | รายการที่ซื้อวันนี้ทั้งหมด + ยอดรวม |
| `งบ` หรือ `กำไร` | กำไรขาดทุนเดือนนี้ (ต้องติดตั้ง [accounting.gs](./ACCOUNTING-README.md) ด้วย) |
| `ช่วย` หรือ `วิธีใช้` | ดูวิธีพิมพ์ |

## บอทจะเก็บข้อความไหนลงชีต

| ที่ไหน | เก็บเมื่อ |
|---|---|
| **แชทส่วนตัวกับบอท** | ทุกข้อความที่อ่านเป็นรายการของได้ พิมพ์ชื่อของได้เลย |
| **ในกลุ่ม** | ต้องขึ้นต้นด้วย `ซื้อ` (หรือ `บันทึก` `ลงของ` `เพิ่ม` `#`) — กันไม่ให้บอทเก็บบทสนทนาทั่วไปของกลุ่ม |
| **รูป** | เก็บทุกรูปทั้งในกลุ่มและแชทส่วนตัว |

```
ซื้อ ปลาดอลลี่ 68 บาท 800 กรัม     ← ในกลุ่มพิมพ์แบบนี้
```

อยากให้กลุ่มเก็บทุกข้อความโดยไม่ต้องใส่คำนำหน้า ตั้ง Script Property `INTAKE_GROUP_MODE` = `all`

## ข้อมูลลงที่ไหน

ชีตใหม่ชื่อ **"ซื้อของเข้า"** (สร้างให้อัตโนมัติ):

| คอลัมน์ | ตัวอย่าง |
|---|---|
| วันที่ / เวลา | `2026-08-31` / `14:32:05` |
| เลขที่ | `L20260831-003` |
| สถานที่ | `ครัวกลาง` (ถ้าส่งจากกลุ่มสาขา จะใส่ชื่อสาขานั้น) |
| ผู้บันทึก | ชื่อไลน์ของคนที่ส่ง |
| รายการ | `ปลาดอลลี่` ← ชื่อที่จับคู่กับชีตรายการสินค้าได้ |
| ชื่อที่พิมพ์มา | `สลีปดอลลี่` ← เก็บของเดิมไว้ด้วย เผื่อจับผิดตัว |
| จำนวนเงิน / น้ำหนัก(กรัม) / บาท/กก. | `68` / `800` / `85` |
| จำนวน / หน่วย | `3` / `ถุง` |
| ที่มา | `ข้อความ` หรือ `รูป` |
| ข้อความต้นฉบับ / messageId | ไว้ย้อนดูว่าเดิมพิมพ์มาว่าอะไร |

> ⚠️ **ไม่แตะชีต "จำนวนของเข้า"** โดยตั้งใจ — ชีตนั้นเก็บ *จำนวนไม้* ไว้คิดยอดสต็อกคงเหลือ
> ถ้าเอาน้ำหนักและราคาไปปนกัน ยอดคงเหลือจะเพี้ยนทันที ชีตนี้จึงเป็นบันทึก
> **ต้นทุนของที่ซื้อเข้ามา** แยกอีกใบ

ชื่อไหนไม่ตรงกับชีตรายการสินค้า ก็ยัง**บันทึกให้ตามที่พิมพ์มา** แล้วติดดอกจัน `*` ในข้อความตอบกลับ — ของที่ซื้อมาแล้วต้องไม่หายไปไหน

## ขั้นตอนติดตั้ง

### 1) เอาโค้ดเข้า Apps Script

1. เปิด Google Sheets ของร้าน → **ส่วนขยาย (Extensions)** → **Apps Script**
2. กด **+** ข้าง "ไฟล์" → **สคริปต์** → ตั้งชื่อ `line-intake`
3. คัดลอกโค้ดทั้งหมดจาก [`line-intake.gs`](./line-intake.gs) ไปวาง → **บันทึก** (Ctrl+S)

> ⚠️ ต้องอยู่ **โปรเจกต์เดียวกับ `pos-backend.gs`** เพราะ Apps Script มี `doPost` ได้ตัวเดียวต่อโปรเจกต์
> — `doPost` ใน `pos-backend.gs` จะเรียก `handleLineIntake_` ให้เอง

### 2) ตั้ง Script Properties

ไอคอน **เฟือง (Project Settings)** ด้านซ้าย → เลื่อนลงไปที่ **Script Properties**:

| Property | ใส่อะไร | จำเป็นไหม |
|---|---|---|
| `LINE_CHANNEL_ACCESS_TOKEN` | token ของบอท (ดู [README.md](./README.md) ขั้นตอนที่ 1) | ✅ จำเป็น |
| `ANTHROPIC_API_KEY` | คีย์จาก https://console.anthropic.com | ใส่ก็ต่อเมื่ออยากให้ Claude อ่านรูปแทน OCR ฟรี |

ตรวจด้วยว่า **Time zone** เป็น `(GMT+07:00) Bangkok`

### 2.5) เปิด Drive API — สำหรับอ่านรูปฟรี

ข้ามข้อนี้ได้ถ้าจะพิมพ์ข้อความอย่างเดียว

1. ในหน้า Apps Script ดูแถบซ้าย หัวข้อ **บริการ (Services)** → กด **+**
2. เลื่อนหา **Drive API** → กด **เพิ่ม (Add)**
3. เสร็จแล้วรัน `setupLineIntake` ใหม่ ต้องขึ้นว่า `ใช้ OCR ของ Google Drive — ฟรี ✅`

ครั้งแรกที่รันหลังเปิดบริการ ระบบจะขอสิทธิ์เข้าถึง Google Drive และ Google Docs เพิ่ม
ให้กด**อนุญาต** — สคริปต์ใช้แค่ตอนแปลงรูปเป็นตัวหนังสือ แล้ว**ลบไฟล์ชั่วคราวทิ้งทันที**
ทุกครั้ง ไม่มีอะไรค้างอยู่ในไดรฟ์

### 3) Deploy เป็นเว็บแอป

**Deploy** → **New deployment** → ⚙️ → **Web app**

| ช่อง | เลือก |
|---|---|
| Execute as | **Me** |
| Who has access | **Anyone** ← ต้องเป็นอันนี้ ไม่งั้น LINE ยิงเข้าไม่ได้ |

คัดลอก **Web app URL** ที่ได้มา (หน้าตา `https://script.google.com/macros/s/AKfy.../exec`)

> ถ้าเคย deploy อยู่แล้ว ให้ **Manage deployments** → ✏️ → Version: **New version** → Deploy
> URL เดิมจะใช้ได้ต่อ ไม่ต้องไปแก้ที่หน้าเว็บร้าน

### 4) บอก LINE ว่าให้ส่งมาที่ไหน

1. https://developers.line.biz/console/ → Channel ของบอท → แท็บ **Messaging API**
2. **Webhook settings** → วาง Web app URL ที่ได้จากข้อ 3 → **Update**
3. เปิดสวิตช์ **Use webhook** ← ต้องเปิดค้างไว้ตลอด
4. ปิด **Auto-reply messages** ที่ LINE Official Account Manager ไม่งั้นบอทจะตอบข้อความสำเร็จรูปแทรกมาด้วย

### 5) ทดสอบ

รันฟังก์ชันจากเมนูด้านบนของ Apps Script (ครั้งแรกจะขอสิทธิ์ ให้กดอนุญาต):

| ฟังก์ชัน | ทำอะไร |
|---|---|
| `setupLineIntake` | สร้างชีต "ซื้อของเข้า" + บอก Webhook URL + บอกว่าอ่านรูปด้วยทางไหน |
| `testIntakeParse` | ลองแยกข้อความตัวอย่างให้ดู โดยไม่ต้องส่งไลน์จริง (ดูผลใน **บันทึกการดำเนินการ**) |
| `testIntakeOcr('File ID')` | ลอง OCR ฟรีกับรูปบิลที่อัปโหลดไว้ในไดรฟ์ (File ID เอามาจาก URL ของไฟล์) |

แล้วทักบอทในไลน์ว่า `ปลาดอลลี่ 68 บาท 800 กรัม` — ต้องมีข้อความตอบกลับและมีแถวใหม่ในชีต

### 6) ล็อกไม่ให้คนนอกยิงเข้ามา (แนะนำ)

Apps Script อ่าน header ของ request ไม่ได้ จึงตรวจลายเซ็น `X-Line-Signature` ของ LINE ไม่ได้
ใครรู้ URL ก็ยิงข้อมูลปลอมเข้ามาได้ — ล็อกด้วยการระบุว่ารับจากใครบ้าง:

1. ให้ทุกคนที่จะใช้ ทักบอทหรือพิมพ์ในกลุ่มคนละครั้ง
2. รัน `showIntakeSenders` → จะเห็นรายชื่อ id ที่เคยส่งเข้ามา
3. ก๊อปบรรทัดที่มันบอกไปรัน เช่น `allowIntakeSenders('Cxxxx', 'Uyyyy')`

หลังจากนี้บอทจะรับเฉพาะต้นทางเหล่านี้ ที่เหลือทิ้งหมด (ยกเลิกด้วย `clearIntakeAllow`)

## ตั้งค่าเพิ่มเติม

Script Properties ที่ใส่เพิ่มได้:

| Property | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `INTAKE_ALLOW` | *(ว่าง = รับหมด)* | รายชื่อ Group ID / User ID ที่อนุญาต คั่นด้วย comma |
| `INTAKE_GROUP_MODE` | `prefix` | ในกลุ่มต้องมีคำนำหน้า ใส่ `all` = เก็บทุกข้อความที่อ่านออก |
| `INTAKE_DEFAULT_LOCATION` | `ครัวกลาง` | สถานที่ที่ใช้เมื่อส่งจากแชทส่วนตัว |
| `INTAKE_IMAGE_MODE` | `auto` | อ่านรูปด้วยทางไหน — `ocr` ฟรีอย่างเดียว · `claude` เสียเงินอย่างเดียว · `off` ไม่อ่านรูป · `auto` มีคีย์ใช้ Claude ไม่มีใช้ OCR |
| `INTAKE_MODEL` | `claude-opus-5` | รุ่นที่ใช้ตอนอ่านด้วย Claude ใส่รุ่นถูกกว่าได้ถ้าอยากประหยัด |

> ตั้ง `ANTHROPIC_API_KEY` ไว้แล้วแต่อยากกลับไปใช้ของฟรี — ตั้ง `INTAKE_IMAGE_MODE` = `ocr`
> ไม่ต้องลบคีย์ทิ้ง

ถ้ากลุ่มไลน์ของสาขาถูกตั้ง `LINE_GROUPS` ไว้แล้ว (สำหรับแจ้งเตือนของหมดอายุ) ของที่ส่งจากกลุ่มนั้น
จะลงช่อง "สถานที่" เป็นชื่อสาขานั้นให้อัตโนมัติ ไม่ต้องตั้งอะไรเพิ่ม

แก้ในโค้ดได้อีก 2 จุด:

| ตัวแปร | ความหมาย |
|---|---|
| `INTAKE_ALIAS` | ชื่อที่คนเรียกกันเอง → ชื่อจริงในชีต เช่น `'ดอลลี่': 'ปลาดอลลี่'` |
| `INTAKE_PREFIXES` | คำนำหน้าที่ใช้ได้ในกลุ่ม |

## เจอปัญหา

| อาการ | สาเหตุที่เจอบ่อย |
|---|---|
| ส่งไปแล้วเงียบ ไม่ตอบอะไรเลย | Use webhook ยังไม่เปิด / Webhook URL ไม่ใช่ URL ล่าสุด / deploy แล้วแต่ยังไม่ได้กด **New version** |
| ตอบว่า "อ่านไม่ออกว่าซื้ออะไร" | ในกลุ่มลืมใส่คำนำหน้า `ซื้อ` หรือข้อความไม่มีตัวเลขเลย |
| บอทตอบข้อความสำเร็จรูปแปลก ๆ | ยังไม่ได้ปิด Auto-reply ที่ LINE Official Account Manager |
| ชื่อของจับผิดตัว | เพิ่มคำที่เรียกกันจริงลง `INTAKE_ALIAS` แล้วบันทึกไฟล์ใหม่ |
| รูปตอบว่า `ยังไม่ได้เปิดบริการ Drive API` | ทำข้อ 2.5 — บริการ (Services) → + → Drive API |
| OCR ฟรีอ่านตัวเลขเพี้ยน | ถ่ายให้ตรง ๆ ไม่เอียง แสงพอ เต็มกรอบ · ถ้ายังเพี้ยนบ่อยให้เปิดทาง Claude แทน |
| รูปตอบว่า "ไม่เจอรายการของที่ซื้อ" | บิลไม่มีบรรทัดที่มีทั้งชื่อของและตัวเลขอยู่ด้วยกัน — พิมพ์เป็นข้อความแทน |
| รูปตอบว่า `ANTHROPIC_API_KEY ไม่ถูกต้อง` | คีย์ผิด หรือเครดิตในบัญชี Anthropic หมด |
| บันทึกซ้ำสองแถว | ปกติกันไว้ด้วย messageId แล้ว ถ้ายังเจอ ให้พิมพ์ `ลบ` แล้วแจ้งไว้ |

ดูรายละเอียดข้อผิดพลาดได้ที่ Apps Script → **บันทึกการดำเนินการ (Executions)**

## หมายเหตุ

- ตอบกลับใช้ **reply token** ซึ่ง**ไม่กินโควต้าข้อความฟรี 200 ข้อความ/เดือน** ของ LINE
  (จะกินก็ต่อเมื่อ token หมดอายุแล้วระบบต้อง push ตามไป ซึ่งเกิดน้อยมาก)
- ข้อความเดียวบันทึกได้สูงสุด 30 รายการ
- รูปใหญ่เกิน 3.5 MB ระบบจะดึงรูปย่อจาก LINE มาอ่านแทนให้เอง
- OCR ฟรีทำงานโดยแปลงรูปเป็น Google Docs ชั่วคราวในไดรฟ์ อ่านตัวหนังสือออกมา
  แล้ว**ลบไฟล์ทิ้งทันที**ทุกครั้ง — ไม่มีไฟล์ค้างสะสม และไม่นับเป็นพื้นที่ไดรฟ์
- OCR ฟรีอ่านออกมาเป็นตัวหนังสือเฉย ๆ แล้วส่งต่อให้ตัวแยกคำชุดเดียวกับที่ใช้กับข้อความ
  บรรทัดยอดรวม ภาษี เงินทอน วันที่ เลขที่บิล ถูกกรองทิ้งก่อน ไม่ให้กลายเป็นรายการของ
- ไฟล์นี้ไม่ยุ่งกับระบบเดิมเลย — POS ของเข้าครัวกลาง เช็คสต็อก แจ้งเตือนของหมดอายุ ทำงานเหมือนเดิมทุกอย่าง
