# 🧮 ระบบ POS หม่าล่าหน้าแดง — วิธีติดตั้ง

ระบบคิดเงินหน้าร้านแบบเครื่องคิดเลข + เก็บข้อมูลลง Google Sheets + หน้าสรุปยอดเป็นกราฟ

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| [`pos.html`](../pos.html) | หน้าคิดเงินหน้าร้าน (พนักงาน + เจ้าของ) |
| [`pos-dashboard.html`](../pos-dashboard.html) | หน้าสรุปยอดขาย/กราฟ (เจ้าของร้านดู) |
| [`pos-backend.gs`](./pos-backend.gs) | โค้ดหลังบ้าน วางใน Google Apps Script |

## สรุปวิธีคิดเงิน

- **ไม้หม่าล่า** ไม้ละ 10 บาท และ 15 บาท (กรอกแยกกัน)
- **มาม่า** 10 / 15 / 20 / 35 / 45 บาท
- **น้ำจิ้ม** กดเลือกอย่างเดียว (น้ำจิ้มงา / น้ำจิ้มสุกี้ / ไม่เอาน้ำจิ้ม) ไม่คิดเงิน แต่ระบบนับให้ว่าให้น้ำจิ้มไปกี่ถ้วย
- **ส่วนลด: ครบทุก 10 ไม้ ลด 5 บาท** — นับจาก **จำนวนไม้** ไม่ใช่ยอดเงิน
  - ซื้อ 10 ไม้ (100 บาท) → ลด 5 บาท → จ่าย 95 บาท ✅
  - ซื้อ 9 ไม้ + มาม่า 10 บาท (รวม 100 บาท) → **ไม่ลด** จ่ายเต็ม 100 บาท ✅
  - ซื้อ 20 ไม้ → ลด 10 บาท (ครบ 2 รอบ)
  - ไม้ 15 บาท ก็นับเป็นไม้เหมือนกัน เช่น 10 ไม้ (150 บาท) → ลด 5 บาท

ถ้าอยากแก้ราคา/ส่วนลด เปิด `pos.html` แล้วแก้ตรงหัวไฟล์ในส่วน `<script>`:

```js
const STICK_PRICES = [10, 15];               // ราคาไม้
const MAMA_PRICES  = [10, 15, 20, 35, 45];   // ราคามาม่า
const DISCOUNT = { perSticks: 10, baht: 5 }; // ครบ 10 ไม้ ลด 5 บาท
```

## ขั้นตอนที่ 1: สร้าง Google Sheets + วางโค้ดหลังบ้าน

1. สร้าง **Google Sheets ใหม่** ตั้งชื่อเช่น "ยอดขาย POS หม่าล่าหน้าแดง"
2. เมนู **ส่วนขยาย (Extensions)** → **Apps Script**
3. ลบโค้ดเดิมทั้งหมด → คัดลอกโค้ดจาก [`pos-backend.gs`](./pos-backend.gs) มาวาง → กด **บันทึก** (Ctrl+S)
4. เลือกฟังก์ชัน **`setupPos`** ที่แถบด้านบน → กด **เรียกใช้ (Run)**
   - ครั้งแรกจะขึ้นให้ **อนุญาตสิทธิ์** → เลือกบัญชี → "ขั้นสูง" → "ไปที่ ... (ไม่ปลอดภัย)" → อนุญาต
   - เสร็จแล้วในไฟล์ Sheets จะมี 3 ชีต: `POS_Orders` · `ผู้ใช้งาน` · `Sessions`

> 💡 ระบบนี้แยกไฟล์ Sheets กับระบบสต็อกเดิม เพื่อไม่ให้ข้อมูลปนกันและ deploy ทับกัน

## ขั้นตอนที่ 2: Deploy เป็น Web app

1. ใน Apps Script กด **Deploy** → **New deployment**
2. ไอคอนเฟือง ⚙️ ข้าง "Select type" → เลือก **Web app**
3. ตั้งค่า:
   - **Execute as:** `Me` (บัญชีเรา)
   - **Who has access:** `Anyone` ← ต้องเป็นอันนี้ เว็บถึงจะเรียกได้
4. กด **Deploy** → คัดลอก **Web app URL** (ลงท้ายด้วย `/exec`) เก็บไว้

> ⚠️ ทุกครั้งที่แก้โค้ดหลังบ้าน ต้องกด **Deploy → Manage deployments → ✏️ → Version: New version → Deploy** ไม่งั้นของเก่าจะยังทำงานอยู่

## ขั้นตอนที่ 3: ตั้งรหัสผู้ใช้

เปิดชีต **`ผู้ใช้งาน`** จะมีตัวอย่างให้แล้ว 2 บรรทัด — แก้เป็นของจริงได้เลย

| username | password | ชื่อ | สาขา | ใช้งาน | สิทธิ์ |
|---|---|---|---|---|---|
| owner | 1234 | เจ้าของร้าน | ตลาดทรัพย์พัฒนา | ใช่ | เจ้าของ |
| staff1 | 1234 | พนักงานตลาดทรัพย์ฯ | ตลาดทรัพย์พัฒนา | ใช่ | พนักงาน |
| staff2 | 1234 | พนักงานแบริ่ง | แบริ่ง | ใช่ | พนักงาน |

**สิทธิ์** เป็นตัวแยกว่าใครเห็นอะไร — ระบบดูจากบัญชีที่ login ไม่ต้องเลือกเอง

| | พนักงาน | เจ้าของร้าน |
|---|---|---|
| หน้าคิดเงิน | ✅ | ✅ |
| ฟันเฟือง ⚙️ แก้ QR รับเงิน | ❌ ไม่มีปุ่มให้กด | ✅ |
| ดู data / สรุปยอด 📊 | ❌ ไม่มีปุ่ม และเปิดลิงก์ตรงก็ไม่ได้ | ✅ |

**คำที่นับว่าเป็นเจ้าของร้าน** (พิมพ์ในช่อง "สิทธิ์" คำใดคำหนึ่ง): `เจ้าของร้าน` · `เจ้าของ` · `ผู้จัดการ` · `owner` · `admin` · `แอดมิน` · `manager`
เว้นว่างหรือพิมพ์อย่างอื่น (เช่น `พนักงาน`) = พนักงาน

> 🔒 หน้า login มีปุ่มตั้งค่าไว้ให้ใส่ URL ของระบบตอนติดตั้งเครื่องใหม่เท่านั้น
> **แก้ QR รับเงินไม่ได้** จนกว่าจะ login ด้วยบัญชีเจ้าของร้าน

- **สาขา** สำคัญมาก — ระบบใช้เลือก QR รับเงินของสาขานั้น และใช้แยกยอดขายในหน้าสรุป
- ปิดการใช้งานพนักงานที่ออกแล้ว: เปลี่ยนช่อง "ใช้งาน" เป็น `ไม่`
- อยากซ่อนรหัสผ่านไม่ให้อ่านได้จากชีต: รันฟังก์ชัน `makeHashedPassword` (แก้รหัสในโค้ดก่อน) แล้วเอาค่า `sha256:...` ที่ได้ใน Log ไปใส่แทนรหัสธรรมดา

## ขั้นตอนที่ 4: เปิดเว็บและตั้งค่า

1. เปิดไฟล์ `pos.html` (จะเปิดจากเครื่อง หรืออัปขึ้น GitHub Pages ก็ได้)
2. กดปุ่ม **⚙️ ตั้งค่าระบบ** ที่หน้า login
3. วาง **Web app URL** จากขั้นตอนที่ 2
4. **อัปโหลดรูป QR รับเงินของแต่ละสาขา** (กดปุ่ม 📷 แล้วเลือกรูป — จะเป็นรูปที่เซฟไว้ หรือถ่ายจากจอก็ได้)
   ระบบจะอ่านโค้ดในรูปแล้วจัดการให้เอง 3 แบบ:

   | รูปที่อัปโหลด | ระบบทำอะไร |
   |---|---|
   | **QR พร้อมเพย์** | อ่านเบอร์พร้อมเพย์ออกมา แล้วสร้าง QR ใหม่ที่**ใส่ยอดเงินให้ทุกบิล** |
   | **QR ธนาคารอื่น** (เช่น Make by KBank / QR ร้านค้า) | เติมยอดเงินลงในโค้ดเดิมให้ — มีสวิตช์ปิดได้ถ้าลูกค้าสแกนแล้วมีปัญหา |
   | **รูปที่อ่านโค้ดไม่ออก** | เอารูปนั้นมาแสดงตรง ๆ (แบบนี้ลูกค้าต้องพิมพ์ยอดเอง) |

   - แต่ละสาขาใส่คนละรูปได้ เงินเข้าคนละบัญชี
   - จะพิมพ์เบอร์พร้อมเพย์เองก็ได้ กดที่ "หรือพิมพ์เบอร์พร้อมเพย์เอง"
5. กด **บันทึก** → login → ใช้งานได้เลย

> ค่าที่ตั้งจะเก็บอยู่ในเครื่อง/เบราว์เซอร์นั้น ๆ ถ้าเปลี่ยนเครื่องหรือเปลี่ยนเบราว์เซอร์ต้องตั้งใหม่
> ถ้าอยากให้ตั้งมาให้เลยไม่ต้องกรอกทุกเครื่อง ให้แก้ค่า `DEFAULT_API_URL` และ `DEFAULT_BRANCH_QR` ที่หัวไฟล์ `pos.html` (และ `DEFAULT_API_URL` ใน `pos-dashboard.html`)

## อยากลองกดเล่นก่อน (ไม่ต้องตั้ง Apps Script)

เปิด `pos.html` → ที่หน้า login กด **🧪 ลองใช้ดูก่อน — ไม่ต้อง login** → เลือกสาขา ใส่ชื่อ → **เริ่มโหมดทดลอง**

- กดเล่นได้ทุกหน้า คิดเงิน · ส่วนลด · เลือกวิธีจ่าย · หน้าสรุปยอด (ใช้ข้อมูลตัวอย่าง)
- **ยอดขายจะไม่ถูกบันทึกที่ไหนทั้งนั้น** และไม่มีการต่อกับ Google Sheets เลย
- เลือกได้ว่าจะลองในมุม **พนักงาน** หรือ **เจ้าของร้าน**
- อยากเห็น QR จริง ๆ ให้ลองในมุมเจ้าของ แล้วกด ⚙️ อัปโหลดรูป QR ของร้าน (ส่วนนี้ไม่ต้องใช้ Apps Script)
- ออกจากโหมดทดลองด้วยปุ่ม ⏻ มุมขวาบน

พอจะใช้จริงค่อยทำขั้นตอนที่ 1–4 ด้านบน

## การใช้งานหน้าร้าน

1. **พิมพ์จำนวนไม้ลงในช่องได้เลย** ทั้งช่อง ไม้ละ 10฿ และ ไม้ละ 15฿ (หรือกดปุ่ม − / + ก็ได้)
2. **มาม่า** กรอกแบบเดียวกัน — พิมพ์จำนวนห่อลงในช่องของราคานั้น
3. กดเลือก **น้ำซุป / ความเผ็ด / น้ำจิ้ม**
4. ส่วนลดครบ 10 ไม้ ระบบลดให้เอง (มีบอกด้วยว่า "อีกกี่ไม้ลดเพิ่ม 5 บาท")
5. กด **ชำระเงิน** → เลือกวิธีจ่าย
   - **1. เงินสด** → ขึ้น "มีเงินเข้าแล้ว" ทันที
   - **2. สแกน/โอนผ่านธนาคาร** → ขึ้นยอด → กด "ถัดไป" → ขึ้น QR พร้อมยอด → ลูกค้าสแกนจ่าย → กด "✓ เงินเข้าแล้ว"
   - **3. ไทยช่วยไทย** → ขึ้น "มีเงินเข้าแล้ว" ทันที
6. ขึ้นหน้า **จ่ายเงินสำเร็จ** แล้วกลับหน้าเครื่องคิดเลขอัตโนมัติใน 5 วินาที

**เน็ตหลุดก็ขายต่อได้** — ออเดอร์ที่ส่งขึ้น Sheets ไม่ทันจะถูกเก็บไว้ในเครื่อง (มีป้าย "⏳ รอส่ง" ที่หัวจอ)
และจะส่งขึ้นให้เองเมื่อเน็ตกลับมา / ขายบิลถัดไปสำเร็จ · QR พร้อมเพย์สร้างในเครื่อง ไม่ต้องใช้เน็ต

## หน้าสรุปยอด (`pos-dashboard.html`)

กดปุ่ม **📊 สรุปยอด** ที่หัวจอของหน้าคิดเงิน จะเห็น:

- **ตัวเลขสรุป** — จำนวนออเดอร์ · ยอดขายสุทธิ · **ยอดเฉลี่ยต่อบิล (ticket average)** · จำนวนไม้ · ส่วนลดที่ให้ไป
- **กราฟยอดขายรายวัน**
- **น้ำซุปที่ลูกค้าสั่งมากที่สุด** เรียงจากมากไปน้อย
- **ระดับความเผ็ด** เรียงจากมากไปน้อย
- **วิธีชำระเงิน** เรียงจากมากไปน้อย (พร้อมยอดเงินของแต่ละวิธี)
- **น้ำจิ้ม** ลูกค้าเลือกอันไหนมากสุด เรียงจากมากไปน้อย + ตัวเลขรวมว่าให้น้ำจิ้มไปกี่ถ้วย
- **ตารางสรุปรายวัน** + ปุ่มดาวน์โหลด CSV

กรองได้ตามช่วงวัน (วันนี้ / 7 วัน / 30 วัน / เดือนนี้ / กำหนดเอง) และตามสาขา

## ปัญหาที่เจอบ่อย

| อาการ | วิธีแก้ |
|---|---|
| Login แล้วขึ้น "เชื่อมต่อ Server ไม่ได้" | URL ผิด หรือตอน Deploy ไม่ได้ตั้ง **Who has access = Anyone** |
| ขึ้น "ยังไม่ได้ติดตั้งระบบ" | ยังไม่ได้รันฟังก์ชัน `setupPos` |
| แก้โค้ดหลังบ้านแล้วไม่มีอะไรเปลี่ยน | ต้อง Deploy **New version** ทุกครั้ง |
| หน้า QR ขึ้นว่ายังไม่ได้ตั้งค่า | กด ⚙️ แล้วอัปโหลดรูป QR ของสาขานั้น |
| อัปโหลดรูปแล้วขึ้นว่าอ่านโค้ดไม่ออก | ถ่ายใหม่ให้ QR เต็มกรอบ ชัด ไม่เอียง ไม่มีแสงสะท้อน |
| ลูกค้าสแกน QR ธนาคารแล้วจ่ายไม่ได้ | กด ⚙️ แล้วปิดสวิตช์ "ใส่ยอดเงินลงใน QR ให้อัตโนมัติ" ของสาขานั้น ระบบจะใช้ QR เดิมแทน (ลูกค้าพิมพ์ยอดเอง) |
| พนักงานไม่เห็นปุ่ม ⚙️ / 📊 | ถูกต้องแล้ว — ต้อง login ด้วยบัญชีที่ตั้งสิทธิ์เป็น "เจ้าของ" |
| หน้าสรุปยอดว่าง | ยังไม่มีบิลในช่วงวันที่เลือก ลองกด "ทั้งหมด" |
| ป้าย "⏳ รอส่ง" ไม่หายสักที | เน็ตยังไม่กลับมา หรือ token หมดอายุ — login ใหม่แล้วขายอีก 1 บิล ระบบจะส่งของค้างขึ้นให้ |
